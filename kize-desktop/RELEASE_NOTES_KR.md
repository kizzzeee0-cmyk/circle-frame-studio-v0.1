KIZE DESIGN TOOL v0.15.0 — 3개 편집기 통합 기반 / 캐릭터 팔레트 / 선택 표시 수정

■ 수정
- Ctrl+A 등 여러 영역 선택 상태에서 이미지 전체에 반투명 보라색이 얹히던 표시를 제거. 선택 영역의 외곽 윤곽만 하늘색으로 표시해 원본 색감과 투명 배경을 그대로 볼 수 있습니다.
- '선택 윤곽선 표시' ON/OFF. 색상 미리보기 중 윤곽선 자동 숨김, 미리보기 해제 후 이전 선택 상태 복구.
- 팔레트 조합 적용 및 ZIP 저장은 이전 v0.14의 멀티컬러 기능 유지. 팔레트 적용 후에도 부분 색상 탭에서 다시 선택/변경/Undo 가능.

■ 캐릭터 사진으로 팔레트 추천
- PNG/JPG/WEBP 참고 사진 업로드와 드래그 앤 드롭, 확대·축소, 사진 클릭 스포이드, 이미지의 투명 픽셀 제외.
- 대표색 5~8개 분석, HEX 직접 입력·역할 지정·잠금·제외·복사·추가. 단순 색상 분류로 머리/눈/의상을 완벽하게 자동 인식하지는 않습니다.
- 12가지 팔레트 유형 생성, 파스텔 정도·밝기·채도·화이트 비중·포인트 강도 조정, 추천 조합을 현재 PNG에 미리보기/적용.
- 마음에 드는 조합은 로컬 라이브러리로 저장하고 JSON 파일로 내보내기. 사진은 외부 서버로 업로드하지 않습니다.

■ 실제 3개 편집기의 오프라인 통합
- KIZE PNG·PSD 편집기(기존 기능 유지)
- Cute Pattern Studio v2.9.1 소스와 렌더링 기능을 Windows 앱 내부에 패키징
- Circle Frame Studio v0.40 소스/React 렌더링을 동일 앱의 오프라인 페이지로 컴파일
- iframe/외부 사이트 연결이 아닌, 같은 Windows 앱 안의 세 편집기를 공통 하늘색 상단 메뉴로 전환
- 공통 팔레트: KIZE에서 저장한 색상을 패턴의 현재 레이어, 원형 프레임의 선택된 프레임 레이어에 실제로 적용
- 작업물 전달: 패턴에서 만든 원본 해상도 PNG → KIZE 색상 편집 → 원형 프레임 미디어 레이어. PNG는 브라우저 내 IndexedDB에 임시 저장하며 서버로 전송하지 않습니다.
- 기존 패턴/원형 프레임의 프로젝트 로컬 저장 기능과 KIZE의 .kize 프로젝트를 유지합니다. 각 프로그램의 독립 포맷이 하나로 변환되지는 않습니다.

■ UI 및 업데이트
- 화이트/연한 하늘색 배경, 포인트 #79BCE5, 주요 버튼 #2B86B5 중심의 통일 UI.
- GitHub Actions 자동 테스트·Windows 설치 프로그램 생성·실행 검사 후 정식 ZIP 릴리스.
- 기존 v0.14의 업데이트 알림·수동 설치 ZIP 방식 유지. 앱이 스스로 exe를 설치하는 서명된 무인 자동 업데이트는 아직 제공하지 않습니다.

■ 미완료 / 후속 작업 (완료로 표시하지 않음)
- 원형 프레임과 패턴의 모든 세부 패널을 100% 동일한 사이드바 구조로 재설계하지 않았습니다. 공통 상단 메뉴·색상과 실제 도구 패키징부터 반영한 단계입니다.
- 전체 도구의 프로젝트를 하나의 통합 파일로 양방향 편집하거나 KIZE에서 PSD 레이어를 원형 프레임의 개별 벡터 레이어로 완전 변환하지 않습니다.
- 캐릭터 사진에서 머리/눈/의상을 픽셀 단위로 확정 구분하려면 추가 분석 모듈이 필요합니다. 현재는 사용자가 수동 역할을 고를 수 있습니다.
- PSD 모든 레이어 효과, 600MB 실물 PSD, 영상 출력 전체를 새 통합 Windows 설치 프로그램에서 추가 샘플 검증하는 것은 별도 작업입니다.
- Cloudflare Pages에 연결된 실제 운영 배포/워크플로는 GitHub 코드만으로 확인할 수 없습니다. 기존 웹사이트를 이번 통합 빌드로 자동 교체하지 않습니다.

실제 사용:
1. 상단 KIZE STUDIO에서 색상 편집 / 큐트 패턴 / 원형 프레임 전환.
2. 색상 편집의 팔레트 조합 탭에서 '캐릭터 사진으로 팔레트 만들기'를 펼쳐 사진 업로드.
3. 추천 조합 클릭→미리보기→'이 팔레트 적용'. 필요하면 부분 색상 탭에서 추가 수정.
4. 선택 시 실제 컬러를 보려면 '선택 윤곽선 표시'를 끄세요. 미리보기 동안에는 자동 숨김됩니다.
5. 패턴에서 '색상 편집기로 보내기', KIZE에서 '원형 프레임으로 보내기'로 PNG 작업물 전달.
