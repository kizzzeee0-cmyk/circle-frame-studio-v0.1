KIZE DESIGN TOOL v0.13.0

PNG 팔레트 조합의 동작을 근본적으로 수정하고, 전체 선택 기능을 추가했습니다.

- **전체 선택 (투명 제외)** 버튼과 Ctrl+A: PNG의 투명하지 않은 그림 전체를 선택합니다. PSD에서는 현재 활성 레이어의 편집 가능 픽셀만 안전하게 선택합니다.
- **진짜 다색 팔레트 적용:** 이전에는 3색 팔레트로 3개의 단색 PNG가 만들어졌지만, 이제 원본의 여러 색상 계열을 각 팔레트 색상에 1:1로 대응해 하나의 PNG에서 동시에 변경합니다.
- 원본의 대표 색상 → 변경할 팔레트 색상을 바로 보이는 색상칩과 HEX로 표시합니다.
- 단색 모드와 팔레트 조합 모드를 명확하게 분리하고 PNG는 '전체 색상 조합 적용'을 기본으로 선택합니다.
- PNG 전체 적용은 별도 부분 선택 없이 사용할 수 있습니다. 필요하면 '선택한 부분만'도 지정할 수 있습니다.
- **조합 미리보기**: 원본 파일을 수정하지 않고 바뀔 색상을 바로 확인합니다.
- **팔레트 조합을 PNG에 적용**: 실제 편집기 이미지에 적용하며 Ctrl+Z로 이전 색상으로 돌아갈 수 있습니다.
- **ZIP 저장**: 선택한 조합 1종 또는 선택 조합+추천 3종을 각각 완성된 다색 PNG로 저장합니다. ZIP 저장만으로 편집기 화면의 색상이 자동 변경되지는 않습니다.
- ZIP에 포함된 palette-mapping.json에서 어떤 원본 색이 어떤 선택 색으로 바뀌었는지 확인할 수 있습니다.
- 원본 캔버스 크기, 알파 투명도, 완전한 흰색/검정 외곽선을 안전하게 유지하는 옵션을 제공합니다.
- 원본의 서로 다른 색상 계열이 팔레트 수보다 적으면 무리하게 가짜 영역을 생성하지 않고 사용하지 않은 색상을 알려줍니다.
- 기존 PSD 색상별 단색 시안, PSD 외관 보존 편집, 30종 부드러운 팔레트, 사진 보정 숫자 입력, 자동 업데이트 알림 기능은 유지합니다.

PNG 사용 순서: PNG 열기 → 팔레트 조합 선택 → 원본→변경 색상 확인 → 조합 미리보기 → PNG에 적용 → PNG 저장.
ZIP은 여러 완성 시안을 공유/비교하기 위한 파일이며, 적용 버튼과 다릅니다.

※ Photoshop 고급 효과 완전 재현 및 600MB PSD 실물 검증은 여전히 별도 범위입니다.
