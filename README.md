# Circle Frame Studio v0.11

원형 프레임을 만들고 **테두리 외부는 투명 배경**으로 PNG 저장하는 React/Vite 기반 웹앱입니다.

## v0.11 핵심 업데이트

### 1) 프리셋 카테고리 확장
왼쪽 프리셋 상단 카테고리를 더 세분화했습니다.

추가/정리된 카테고리 예시:
- 전체
- 내 프리셋
- 기본
- 미니멀
- 끊긴형
- 도트
- 물결
- 낙서
- 브러시
- 장식
- 하트
- 리본
- 꽃
- 별/반짝이
- 그라데이션
- 글로우
- 3D
- 추상
- 4컬러

### 2) 카테고리 숨김 문제 수정
- 카테고리 버튼이 오른쪽으로 밀려 **숨겨지던 문제**를 수정했습니다.
- 이제 카테고리 영역이 **여러 줄로 자동 줄바꿈**되어, 스크롤 없이 한눈에 전부 볼 수 있습니다.

### 3) 프리셋 목록 안내 강화
- 현재 선택된 카테고리/검색 기준으로 **총 프리셋 개수**를 표시합니다.

## 유지 기능
- 1/2/3/4색 패턴 반복 유지
- PNG 업로드 반복 프레임 유지
- 미리보기 = 저장 결과 일치 유지
- 2000×2000 투명 PNG 저장 유지
- 단일 프레임 구조 유지
- v0.10 ~ v0.3 자동 저장 데이터 불러오기 유지

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173/` 접속.

## 빌드

```bash
npm run build
```
