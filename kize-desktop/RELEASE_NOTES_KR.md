KIZE DESIGN TOOL v0.14.0

사용자 피드백 기반 색상 편집 사용성 개선

- '팔레트 조합(여러 색 한번에)'과 '부분 색상(한 색만)'을 독립된 두 탭으로 분리했습니다. PNG를 불러오면 팔레트 조합 탭을 먼저 보여줘 기존 단색 편집 설정과 혼동하지 않습니다.
- '선택한 팔레트 조합 적용하기'를 추천 팔레트 선택 바로 아래의 큰 버튼으로 이동했습니다. 아래로 계속 스크롤할 필요가 없습니다.
- 추천 팔레트 30종을 고르면 PNG의 여러 색상을 한꺼번에 바꾼 결과를 자동으로 미리 보여줍니다. 이때 실제 PNG 픽셀은 변경되지 않습니다.
- 마음에 들면 '선택한 팔레트 조합 적용하기' 버튼을 클릭해 편집 화면에 확정합니다. Ctrl+Z로 되돌릴 수 있습니다.
- 지난번의 '색상별 단색 시안' 옵션이 선택되어 있어도, PNG의 팔레트를 새로 고르면 여러 색을 동시에 변경하는 조합 모드로 자동 전환합니다.
- 팔레트 탭에서는 위쪽 단색 변경 HEX 입력과 버튼을 숨겨 서로 다른 기능을 잘못 사용하는 상황을 막았습니다. 단색 편집은 별도 탭에서 이용할 수 있습니다.
- 전체 선택 버튼을 두 탭에서 언제든 찾을 수 있으며, Ctrl+A는 모든 보이는 레이어의 편집 가능한 픽셀을 선택합니다.
- 글자 입력칸에 커서가 있다면 기존 텍스트 선택 Ctrl+A를 유지하고, 대신 Ctrl+Shift+A를 누르거나 '그림 전체 선택' 버튼으로 전체 그림을 선택할 수 있습니다.
- 이전에 PNG에서 작업 후 .kize 프로젝트로 저장한 단일 이미지도 팔레트 조합 대상으로 열 수 있게 개선했습니다.
- ZIP은 여러 색이 적용된 완성 PNG 파일을 저장하는 기능으로, 편집 화면의 '팔레트 적용' 버튼과는 다릅니다.
- 기존 PSD 레이어별 색상 편집, 원본 외관 보존, 마스크/클리핑, 30개 파스텔 팔레트, PNG 고화질 출력, 편집 취소 및 업데이트 알림은 유지합니다.

사용 순서: PNG 열기 → 팔레트 조합(기본 탭) → 추천 팔레트 선택(자동 미리보기) → 바로 아래 [선택한 팔레트 조합 적용하기] → PNG 내보내기.

주의: 포토샵에서 캡처한 체크무늬 스크린샷은 원래 투명도가 없을 수 있습니다. 원본 투명 PNG로 작업해야 투명 배경을 그대로 유지할 수 있습니다. 복잡한 PSD 효과의 완전한 자체 재계산은 지원하지 않습니다.
