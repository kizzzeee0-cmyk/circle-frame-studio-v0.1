# KIZE DESIGN TOOL v0.12.0 — 색상 편집 쉬운 사용법과 검증 범위

## 첨부 이미지와 같은 한 장짜리 PNG 프레임 색상 변경
1. PSD/PNG 불러오기로 PNG 원본을 연다.
2. '클릭한 색상만 (기본)'이 선택되어 있는지 확인한다. **전체 에셋**을 고르면 연결된 프레임 전체가 잡힐 수 있으니 프레임 색상만 바꾸려면 기본 선택을 유지한다.
3. 미리보기 중앙에서 바꾸고 싶은 파스텔 색을 클릭한다. 다른 동일색 부분도 바꾸려면 Shift+클릭 또는 '연결된 유사 색상만' 체크를 해제한다.
4. 색상 선택기 또는 정확한 HEX 입력칸에서 원하는 색상을 고른다.
5. '선택한 색상 그대로'를 유지하면 HEX를 정확히 적용하고, '파스텔로 더 부드럽게'를 선택하면 부드러움 비율에 따라 밝아진 HEX를 미리 표시한다.
6. '변경 미리보기'를 눌러 비교한 후 '선택한 부분에 색상 적용'을 누른다. '되돌리기'로 취소할 수 있다.
7. 오른쪽 접힌 '색상별 시안 일괄 생성'에서 추천 30종/HEX 직접 입력/보정 방식 선택 후 ZIP으로 여러 시안을 저장한다. 시안 ZIP을 만드는 작업은 프로젝트를 변경하지 않는다.

## PSD 편집
- 기본 상태에서 캔버스를 클릭하면 가장 위의 **보이는 PSD 레이어**를 자동으로 선택한다. 특정 PSD 레이어에 작업을 한정하려면 왼쪽 '선택한 레이어에 고정'을 켠다.
- Photoshop 저장 합성 픽셀을 보존하는 원본 외관 편집만 지원하는 경우가 있다. PSD 특수 효과·조정·복합 벡터 마스크의 네이티브 변경까지 보장하지 않는다.
- 실제 합성 픽셀에 변화가 없다면 빈 변경을 저장하지 않고 이유를 알려준다. 흰색·검정선 보호를 해제하면 무채색 영역까지 변경할 수 있지만 원본 윤곽 보호 효과도 없어진다.
- PSD 색상 편집 뒤 변경 전후를 확인하기 위해 미리보기와 실제 적용을 구분한다.

## 색상별 시안
- 기본 모드는 **HEX 그대로**, 명암/다색 조화 변환은 선택적이다.
- 파스텔 부드러움은 0~85%이며 0은 입력 HEX 그대로다. 적용 HEX를 미리 보여준다.
- 30개 추천 조합은 작업에 맞춰 추가 편집할 수 있다.
- 파일명과 palette.json은 실제 출력될 기준 HEX 및 원래 입력 HEX를 각각 기록한다.

## 사진 보정
- 노출, 대비, 채도, 색온도, 하이라이트, 그림자 범위 -100~100을 슬라이더와 숫자로 모두 편집한다.
- 사진 속 픽셀을 실제로 재계산하므로 PSD 원본 합성 모드와 완전한 Photoshop 효과 재현이 불가능한 경우 레이어 편집 보기로 전환한다.
- 각 숫자 입력 완료에는 실행 취소 히스토리를 생성한다.

- Microsoft Edge 실사용 통합 테스트: `node tests/browser-color-workflow.mjs` 및 기존 전체 E2E.
