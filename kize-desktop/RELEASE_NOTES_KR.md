KIZE DESIGN TOOL v0.12.0

사용자가 PNG·PSD에서 색상 변경을 쉽게 찾고, 원하는 색을 정확히 적용할 수 있도록 사용성을 크게 개선했습니다.

- PNG와 PSD의 기본 선택을 '클릭한 색상만'으로 설정. 한 장짜리 프레임 PNG에서 전체가 선택되는 문제 완화.
- PNG 전체 캔버스 레이어를 감싸던 점선을 색상 선택 표시와 구분하여 혼동 방지.
- PSD는 클릭 위치의 맨 위 보이는 레이어를 자동 탐지. 특정 레이어에만 고정하는 옵션은 따로 제공.
- 편집 순서를 '① 부분 선택 → ② 색상 지정 → ③ 미리보기 → 적용'으로 안내.
- 원본을 변경하지 않는 색상 미리보기/해제 기능.
- 기본 색상 변경은 고른 HEX 그대로 적용. 명암·다색 조화 옵션은 사용자가 직접 선택했을 때만 적용.
- 파스텔 보정 수준을 슬라이더와 숫자로 조절하고 실제 적용될 HEX를 눈으로 확인.
- HEX 코드를 직접 입력해 색상을 지정하는 입력창 추가.
- 자동으로 색이 바뀌는 일 없이 선택한 기준색을 미리 보여주는 색상별 PNG 시안 ZIP.
- 포근한 파스텔, 캔디, 자연, 차분한 뉴트럴의 30가지 컬러 프리셋.
- 노출/대비/채도/색온도/하이라이트/그림자에 숫자 직접 입력 추가. 슬라이더와 서로 동기화.
- PSD에서 변경 전후가 같아 아무 변화가 없는 경우에는 이유와 해결 안내 제공.
- 고유 PSD 복합 효과/스마트 오브젝트 재계산은 계속 제한되며 미지원 영역은 무리하게 수정하지 않습니다.
- 기존 프로젝트, PSD 마스크, 실행 취소/다시 실행, PNG 출력 동작은 그대로 유지합니다.

설치 방법: ZIP 압축 해제 → KIZE 프로그램 종료 → setup.exe 실행
