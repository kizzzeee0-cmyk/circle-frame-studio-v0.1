# Circle Frame Studio v0.29

원형 프레임을 만들고 **테두리 외부는 투명 배경**으로 PNG 저장하는 React/Vite 기반 웹앱입니다.

## v0.17 핵심 업데이트

### 1) 낙서형 원의 볼록함 세부 조절 추가
이제 Scribble / Rough / Brush 계열에서 아래 항목을 따로 조절할 수 있습니다.

- **거칠기**: 손그림 느낌의 랜덤 흔들림 강도
- **볼록한 정도**: 둥글게 튀어나오는 굴곡 강도
- **볼록 개수**: 볼록한 부분이 몇 개 생길지 조절

즉, 기존처럼 거칠기를 낮춰도 지나치게 볼록한 느낌이 남는 문제를 줄이고,
보다 **매끈한 낙서형**부터 **살짝 손그린 느낌**까지 세밀하게 조절할 수 있습니다.

### 2) 레이어 추가 / 순서 변경 기능
이제 프레임을 **레이어로 여러 개 겹쳐서** 하나의 결과물로 만들 수 있습니다.

지원 기능:
- **레이어 추가**
- **레이어 선택 후 개별 편집**
- **레이어 이름 변경**
- **레이어 보이기 / 숨기기**
- **레이어 순서 위/아래 이동**
- **레이어 삭제**

예를 들어:
- 아래 레이어에는 깔끔한 원형 2중선
- 위 레이어에는 하트 / 별 / 낙서형 라인

처럼 조합해서 **하나의 복합 프레임**을 만들 수 있습니다.

## 유지 기능
- Glow / Shadow 사용 시 원 크기 유지
- 끊긴형(Broken) 균등 길이 유지
- 별/스파클 전체 색상 일괄 변경 유지
- 손그림 2겹 원 프리셋 유지
- 1/2/3/4색 패턴 반복 유지
- PNG 업로드 반복 프레임 유지
- 미리보기 = 저장 결과 일치 유지
- 2000×2000 투명 PNG 저장 유지

- Lavender Flow Subtle
- Pink Flow Soft
- Mint Flow Soft
- Sky Flow Soft
- Peach Flow Soft


## v0.20 — 흰색 + 선택색상 4구간 반복 그라데이션

v0.19의 **흰색 + 선택색상 2구간 흐름**은 그대로 유지하면서,
새로운 **4구간 반복 모드**를 추가했습니다.

4구간 모드는 실제로 선택하는 색상은 2개뿐입니다.

`흰색 → 선택색상 → 흰색 → 선택색상`

- 두 흰색 구간은 항상 같은 길이
- 두 선택색상 구간도 항상 같은 길이
- 흰색 구간 길이를 변경해도 네 구간의 균형이 깨지지 않음
- 연결 부드러움은 남은 색상 구간 범위 안에서 자동 제한되어 급격한 이음선 방지
- 기존 2구간 흐름 모드와 자유형 4색 Gradient Stop 기능 모두 유지

추가 프리셋:
- Lavender 4-Segment Flow
- Lavender 4-Segment Wide White
- Lavender 4-Segment Soft
- Lavender 4-Segment Glossy
- Pink 4-Segment Flow
- Mint 4-Segment Flow
- Sky 4-Segment Flow

조절 항목:
- 입체감 ON/OFF
- 입체감 크기
- 입체감 깊이
- 부드러움
- 빛 방향
- 빛 높이
- 밝은 부분 색상 / 불투명도

마지막으로 원래 프레임 알파 안쪽으로 다시 제한하기 때문에
**프레임 위치·크기와 중앙 투명 영역을 그대로 유지**합니다.

기본 프리셋:
- **도톰한 둥근 링**

## v0.24 — 2색 흐름 6구간 / 8구간

기존 2구간, 4구간에 이어 6구간과 8구간 반복을 추가했습니다.

- 2구간: 흰색 → 선택색상
- 4구간: 흰색 → 선택색상 → 흰색 → 선택색상
- 6구간: 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상
- 8구간: 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상

반복 수가 늘어나도 모든 흰색 구간과 선택색상 구간은 동일한 길이/대칭으로 계산되며,
프리셋 카테고리에 **2색 6구간**, **2색 8구간**을 추가했습니다.


## v0.25 — 최근 저장 내역 10개

PNG 또는 JSON으로 저장할 때 현재 **전체 편집 프로젝트 상태**를 브라우저 로컬 IndexedDB에 자동 기록합니다.

- 최대 10개, 최신순 정렬
- 10개 초과 시 가장 오래된 기록 자동 삭제
- 브라우저 재접속 후에도 유지
- 미리보기 썸네일 + 저장 날짜/시간
- 불러오기 전 큰 미리보기 확인
- 개별 불러오기 / 삭제
- 전체 삭제 전 확인창
- 현재 작업을 덮어쓸 수 있으므로 불러오기 전 확인창

기록 데이터는 단순 이미지가 아니라 전체 `FrameProject` 스냅샷입니다.
따라서 레이어 ON/OFF·순서, 색상, HEX, 그라데이션, 2/4/6/8구간,
경사·엠보스, 글로우, 그림자, 불투명도, 업로드 PNG 프레임 설정까지 복원됩니다.

썸네일은 320×320 WebP로 압축하고, 편집 데이터는 IndexedDB의 구조화 복제 방식으로 저장해
localStorage보다 큰 프로젝트도 안정적으로 보관할 수 있게 했습니다.

## v0.27 — Glitter Ring Studio

첨부 레퍼런스처럼 **부드러운 기본 링 위에 미세 글리터와 큰 4갈래 반짝이가 섞이는 글리터 전용 프레임**을 추가했습니다.

조절 항목:
- 글리터 1/2/3/4색 팔레트
- 글리터 밀도
- 작은 입자 크기
- 큰 반짝이 크기
- 별 반짝이 비율
- 링 주변 퍼짐
- 입자 빛 번짐
- 기본 링 불투명도
- 안쪽/바깥쪽 얇은 빛선
- 랜덤 Seed

입자 위치는 Seed 기반으로 고정되어 **미리보기와 2000×2000 투명 PNG 저장 결과가 동일**합니다.

추가 프리셋:
