KIZE STUDIO v0.16.0 — 하늘색 UI 정리 / 역할 기반 팔레트 색상 치환

■ UI 색상 전면 정리
- 기존의 진한 청록·파랑 포인트를 줄이고 파우더 스카이 / 밀키 블루 중심으로 변경했습니다.
- 주요 액션: #78BCE6, hover: #67ACD8, 소프트 버튼: #C5E6F7, 선택 배경: #EAF6FD.
- 앱 배경은 #F7FBFF, 선은 #D9EAF4, 본문은 #40576A 계열로 정리했습니다.
- 색상 편집기, 통합 상단 메뉴, 큐트 패턴, 원형 프레임의 공통 UI가 같은 하늘색 계열을 사용합니다.
- 큐트 패턴의 '색상 편집기로 보내기' / '심리스 타일 저장'처럼 이전 핑크 텍스트가 남던 버튼도 파란 계열로 명시적으로 통일했습니다.
- 넓은 면적의 장식용 그라데이션은 사용하지 않고 흰색·연하늘 단색 면을 우선합니다.
- 이 변경은 프로그램 UI만 바꾸며 캔버스의 실제 디자인 색상이나 PNG 출력 팔레트에는 영향을 주지 않습니다.

■ 팔레트 색상 치환 — 역할 기반 패밀리 인식
- 기존에는 원본의 큰 색상 덩어리를 각각 독립 색상으로 인식해 팔레트 1/2/3번을 순서대로 배정했습니다.
- 이 방식에서는 같은 핑크 계열의 본체색, 진한 핑크 그림자, 차콜 외곽선이 서로 다른 팔레트 색으로 바뀌어 조합이 깨질 수 있었습니다.
- v0.16부터는 먼저 '독립 색상 패밀리'를 찾고, 같은 계열의 본체·그림자·외곽선을 하나의 색상 역할로 묶습니다.
- 예: 핑크 본체 + 진핑크 그림자 + 어두운 외곽선 → 하늘색 기준색 1개를 사용하고 그림자·외곽선은 그 하늘색의 더 어두운 단계로 자동 파생합니다.
- 진한 중성 외곽선은 주변 본체 색상 패밀리를 우선 상속하므로, 불필요하게 팔레트 한 칸을 소비하지 않습니다.
- 원본의 밝은 면은 기준색보다 밝게, 그림자는 더 어둡게 유지해 입체 관계를 보존합니다.
- '외곽선·그림자·밝은 면의 명도 관계 유지'를 기본 ON으로 변경했습니다.

■ 화질 / 경계 보존
- 원본 PNG 알파값은 픽셀 단위로 그대로 유지합니다.
- 색상 치환 과정에서 리사이즈, 블러, 재샘플링을 하지 않습니다.
- 반투명 안티앨리어싱 가장자리도 원래 투명도를 유지한 채 역할에 맞는 파생색만 계산합니다.
- 완전한 흰색·검정 보호 옵션은 기존처럼 사용할 수 있습니다.

■ 팔레트 매핑 안내 개선
- 매핑 안내를 '원본 색상 → 팔레트 색상'에서 '독립 색상 패밀리 → 기준색' 개념으로 수정했습니다.
- 그림자/외곽선이 별도의 팔레트 색으로 바뀌는 것이 아니라 같은 패밀리의 명도 단계로 유지된다는 설명을 UI에 추가했습니다.

■ 검증
- 같은 색상의 본체 / 그림자 / 중성 외곽선이 하나의 패밀리로 묶이는 단위 테스트 추가.
- 외곽선이 두 번째·세 번째 팔레트 색을 임의로 가져가지 않는지 검증.
- 반투명 가장자리의 알파값이 변하지 않는지 검증.
- 기존 멀티컬러 팔레트, 선택 영역, 흰색·검정 보호 동작은 유지합니다.

■ 제한 / 후속 개선
- 역할 인식은 픽셀의 색상·명도·주변 관계를 이용하는 휴리스틱이며 AI 객체 분할은 아닙니다.
- 서로 완전히 다른 물체가 동일한 색상 계열을 사용하거나, 외곽선이 본체에서 멀리 떨어진 특수 디자인은 수동 '부분 색상' 편집이 더 정확할 수 있습니다.
- 실제 다양한 방송용 배너/프레임 PNG로 추가 샘플을 쌓아 패밀리 인식 기준을 계속 조정할 예정입니다.
