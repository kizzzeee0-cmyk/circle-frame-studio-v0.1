# Circle Frame Studio v0.31

원형 프레임을 만들고 **테두리 외부는 투명 배경**으로 PNG 저장하는 React/Vite 기반 웹앱입니다.

## v0.17 핵심 업데이트

### 1) 낙서형 원의 볼록함 세부 조절 추가
이제 Scribble / Rough / Brush 계열에서 아래 항목을 따로 조절할 수 있습니다.

- **거칠기**: 손그림 느낌의 랜덤 흔들림 강도
- **볼록한 정도**: 둥글게 튀어나오는 굴곡 강도
- **볼록 개수**: 볼록한 부분이 몇 개 생길지 조절

즉, 기존처럼 거칠기를 낮춰도 지나치게 볼록한 느낌이 남는 문제를 줄이고,
보다 **매끈한 낙서형**부터 **살짝 손그린 느낌**까지 세밀하게 조절할 수 있습니다.

### 2) 레이어 추가 / 순서 변경 기능
이제 프레임을 **레이어로 여러 개 겹쳐서** 하나의 결과물로 만들 수 있습니다.

지원 기능:
- **레이어 추가**
- **레이어 선택 후 개별 편집**
- **레이어 이름 변경**
- **레이어 보이기 / 숨기기**
- **레이어 순서 위/아래 이동**
- **레이어 삭제**

예를 들어:
- 아래 레이어에는 깔끔한 원형 2중선
- 위 레이어에는 하트 / 별 / 낙서형 라인

처럼 조합해서 **하나의 복합 프레임**을 만들 수 있습니다.

## 유지 기능
- Glow / Shadow 사용 시 원 크기 유지
- 끊긴형(Broken) 균등 길이 유지
- 별/스파클 전체 색상 일괄 변경 유지
- 손그림 2겹 원 프리셋 유지
- 1/2/3/4색 패턴 반복 유지
- PNG 업로드 반복 프레임 유지
- 미리보기 = 저장 결과 일치 유지
- 2000×2000 투명 PNG 저장 유지

## v0.20 — 흰색 + 선택색상 4구간 반복 그라데이션

v0.19의 **흰색 + 선택색상 2구간 흐름**은 그대로 유지하면서,
새로운 **4구간 반복 모드**를 추가했습니다.

4구간 모드는 실제로 선택하는 색상은 2개뿐입니다.

`흰색 → 선택색상 → 흰색 → 선택색상`

- 두 흰색 구간은 항상 같은 길이
- 두 선택색상 구간도 항상 같은 길이
- 흰색 구간 길이를 변경해도 네 구간의 균형이 깨지지 않음
- 연결 부드러움은 남은 색상 구간 범위 안에서 자동 제한되어 급격한 이음선 방지
- 기존 2구간 흐름 모드와 자유형 4색 Gradient Stop 기능 모두 유지

추가 프리셋:
- Lavender 4-Segment Flow
- Lavender 4-Segment Wide White
- Lavender 4-Segment Soft
- Lavender 4-Segment Glossy
- Pink 4-Segment Flow
- Mint 4-Segment Flow
- Sky 4-Segment Flow

## v0.24 — 2색 흐름 6구간 / 8구간

기존 2구간, 4구간에 이어 6구간과 8구간 반복을 추가했습니다.

- 2구간: 흰색 → 선택색상

- 6구간: 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상
- 8구간: 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상 → 흰색 → 선택색상

반복 수가 늘어나도 모든 흰색 구간과 선택색상 구간은 동일한 길이/대칭으로 계산되며,

## v0.25 — 최근 저장 내역 10개

PNG 또는 JSON으로 저장할 때 현재 **전체 편집 프로젝트 상태**를 브라우저 로컬 IndexedDB에 자동 기록합니다.

- 최대 10개, 최신순 정렬
- 10개 초과 시 가장 오래된 기록 자동 삭제
- 브라우저 재접속 후에도 유지
- 미리보기 썸네일 + 저장 날짜/시간
- 불러오기 전 큰 미리보기 확인
- 개별 불러오기 / 삭제
- 전체 삭제 전 확인창
- 현재 작업을 덮어쓸 수 있으므로 불러오기 전 확인창

기록 데이터는 단순 이미지가 아니라 전체 `FrameProject` 스냅샷입니다.
따라서 레이어 ON/OFF·순서, 색상, HEX, 그라데이션, 2/4/6/8구간,
경사·엠보스, 글로우, 그림자, 불투명도, 업로드 PNG 프레임 설정까지 복원됩니다.

썸네일은 320×320 WebP로 압축하고, 편집 데이터는 IndexedDB의 구조화 복제 방식으로 저장해
localStorage보다 큰 프로젝트도 안정적으로 보관할 수 있게 했습니다.

## v0.30 — Animated Export

실시간 글리터 애니메이션을 실제 움직이는 파일로 내보낼 수 있습니다.

지원 형식:
- Animated WebP — 기본 추천, 투명 배경 + 부드러운 색 + 비교적 작은 용량
- APNG — 반투명 글로우 무손실 보존, 큰 용량
- GIF — 가장 넓은 호환성, 256색/1bit 투명도 제한

설정:
- 500 / 1000 / 2000px
- 12 / 15 / 20 / 24 / 30fps
- 1 / 1.5 / 2 / 2.4 / 3 / 4초
- GIF 반복: 무한 / 1회 / 2회
- WebP 품질
- 저장 전 실제 루프 미리보기
- 진행률 표시
- 고해상도 APNG/WebP 메모리 경고

내보내기는 0→1 정규화 루프 좌표를 사용하고, 글리터 시간 함수도 정수 주기 기반으로 보정해 루프 경계가 자연스럽게 이어집니다.

## v0.34 — Focus UI

기능을 더 늘리기보다 자주 쓰는 기능을 더 빨리 찾고, 드물게 쓰는 설정은 필요할 때만 펼칠 수 있도록 UI 구조를 정리했습니다.

- 오른쪽 프레임/미디어 설정 섹션에 ★ 즐겨찾기 추가
- ★ 표시한 설정 섹션은 자동으로 패널 최상단에 정렬
- 섹션별 접기/펼치기 상태를 브라우저에 기억
- 설정 검색과 모두 접기 / 모두 펼치기 추가
- 기본 상태에서 레이어, 프레임 회전, 고급 효과, 패턴 세부, 세부 애니메이션 등은 접어서 시작
- 프리셋 자체 ★ 즐겨찾기 추가 및 즐겨찾기 우선 정렬
- ★ 즐겨찾기 프리셋 전용 카테고리 추가
- 자주 쓰는 프리셋 카테고리만 먼저 표시하고 나머지는 더보기로 정리
- 내 PNG 반복 프레임 도구를 접히는 도구 상자로 변경
- 배경 세부 편집을 접히는 도구 상자로 변경
- 설정 패널, 레이어 카드, 슬라이더, 버튼, 미디어 추가 영역의 기본 높이와 여백 축소
- 프리셋 목록을 3열 컴팩트 카드로 변경
- 상단 툴바에서 실행취소/저장/내보내기 위주로 노출하고 프로젝트 관리 기능은 메뉴로 정리
- 타임라인 접힘 상태를 기억하고 기본적으로 접힌 상태에서 시작
- 타임라인을 접으면 실제 캔버스 영역이 넓어지도록 레이아웃 수정
- UI 배치 초기화 기능 추가: 작업물은 유지하고 즐겨찾기/접힘 상태만 초기화

즐겨찾기, 접힘 상태, 프리셋 즐겨찾기는 프로젝트 데이터와 별도로 브라우저 로컬 UI 설정에 저장됩니다.
