KIZE DESIGN TOOL v0.11.0

업데이트 확인과 다운로드 방식이 더 간단해졌습니다.

- 실행 시 KIZE 전용 새 버전을 자동 확인합니다.
- 새 버전이 있으면 상단에 작은 NEW 표시가 나타납니다.
- NEW 알림은 해당 버전을 처음 확인한 뒤에는 반복해서 강조하지 않습니다.
- 업데이트 보기를 누르면 버전과 변경 내용을 간단히 볼 수 있습니다.
- ZIP 다운로드 버튼을 누르면 기본 브라우저로 공식 GitHub 배포 파일을 엽니다.
- 설치 파일을 실행하거나 작업 중인 문서를 자동으로 변경하지 않습니다.
- 기존 PSD 마스크·색상 편집·PNG 고화질 출력 기능은 유지합니다.

사용 방법: 설치 ZIP 다운로드 → 압축 해제 → 실행 중인 KIZE 종료 → 설치 EXE 실행

※ 이 방식은 업데이트 알림+수동 설치입니다. 서명키가 필요한 프로그램 내부 완전 자동 설치와는 다릅니다.
